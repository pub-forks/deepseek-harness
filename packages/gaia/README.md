# Gaia packages

English | [中文](README.zh.md)

## Summary

The Gaia package group contains the profile overlay and its host and client extensions. Use these packages to embed DSH in Gaia, manage OAuth accounts, preview Markdown, and add Gaia-specific session commands. Package contracts and limitations are documented in each package README.
